# dev_memory

This directory keeps milestone state so another AI or human can resume safely.

Start with `current.yaml`, then read the current milestone directory:

- `memory.md`: what changed, why, tests, and next entry point
- `decisions.md`: decisions and rejected alternatives
- `patches.yaml`: patch/change records
- `test_report.md`: validation evidence
- `known_issues.md`: known gaps and TODOs
