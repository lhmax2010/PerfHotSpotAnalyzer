# M0.5 Golden Fixtures Test Guide

## Scope

M0.5 establishes the DESIGN §10.4 golden fixture baseline plus the v1.0.4-v1.0.6
incremental contract cases:

- Positive fixtures ①-⑦ must pass `common/schema_validate.py`.
- Negative fixtures ⑧-⑫ must be rejected by `common/schema_validate.py`.
- Incremental fixtures cover capture bundle, ownership, attribution,
  effective_anchor, generic-llm, allocation-reduction, and binary-size top-n
  actionability.

This milestone does not implement perf capture, ingestion adapters, anchor
scoring, patch generation, Tizen device logic, or automatic patch application.

## Prerequisites

- Python 3.11+.
- Dev dependencies from `requirements-dev.txt`.
- No Tizen, GBS, `sdb`, debuginfo, or real `perf` artifacts are required.

## Fixture Layout

Each fixture directory contains:

- `README.md`: what DESIGN §10.4 case it covers
- `notes.md`: human context for future milestone users
- `expected.json`: document name, document type, and pass/fail expectation
- `performance-findings.json`, `patches.json`, or `manifest.json`: contract
  document under test
- optional raw input data for later parser milestones
