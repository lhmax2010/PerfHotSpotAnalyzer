# M0.5 Fixtures Review Package

## Scope

M0.5 adds the DESIGN §10.4 golden fixture baseline, incorporates the v1.0.4-v1.0.6
contract increments, and validates every fixture through `common/schema_validate.py`.

This stage updates contract infrastructure required by v1.0.6: canonical schemas,
schema-copy SHA-256 checks, LLM SDK import scanning, capture-bundle validation,
and actionability/effective_anchor semantic checks. It does not implement A/B
business logic, Tizen device capture, parser adapters, Gate execution, or runtime
patch application.
